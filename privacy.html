Privacy policy

Effective 10 November 2026

This website collects nothing about you, and Past the Plug Publisher only ever accesses the Past the Plug YouTube channel's own data, for its owner.

Who we are

Past the Plug is a YouTube channel (@pasttheplug) run by an individual in the United Kingdom. Contact: pasttheplug@gmail.com.

This website

This site is a static page hosted on GitHub Pages. It sets no cookies, runs no analytics or tracking scripts, loads no third-party fonts and has no forms. GitHub, as the host, may log technical data such as IP addresses for security; see the GitHub Privacy Statement.

Past the Plug Publisher and the YouTube API Services

Past the Plug Publisher is a private command-line tool used only by the channel's owner. It uses YouTube API Services. By using it, its user agrees to the YouTube Terms of Service, and data accessed through YouTube API Services is also covered by the Google Privacy Policy.

What it accesses. With the owner's permission, given through Google sign-in, it accesses the Past the Plug channel only, to:

  • upload the channel's own videos, set their titles, descriptions, thumbnails, captions and publish times;
  • read details of the channel's own videos;
  • read the channel's own YouTube Analytics and reporting data (such as views, watch time, audience retention and impressions).

It does not access any other channel, any viewer's account, comments, subscriber identities or any personal data about viewers. YouTube Analytics data it reads is aggregated and does not identify individuals.

How the data is used. Only to publish the channel's videos and to produce private performance reports for the channel's owner.

Storage and retention. The sign-in token and analytics data are stored on the owner's own computer and private storage, not on any public server. Analytics data is kept for as long as it is useful for reviewing the channel's performance and is deleted within 30 days of access being revoked. Data is refreshed or deleted in line with the YouTube API Services Developer Policies.

Sharing. Data accessed through YouTube API Services is not sold, shared with or shown to anyone other than the channel's owner.

Cookies. Past the Plug Publisher is a command-line tool and does not place cookies or similar technologies on any device.

Revoking access. Access can be removed at any time from the Google account's third-party access settings.

Your rights

If you believe we hold personal data about you, you can ask to see, correct or delete it by emailing pasttheplug@gmail.com. You can also complain to the UK Information Commissioner's Office at ico.org.uk.

Changes

If this policy changes, the new version will be posted here with a new effective date.
